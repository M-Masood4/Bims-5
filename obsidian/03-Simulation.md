# Simulation

BIMS 5 uses **MATSim** (Multi-Agent Transport Simulation) for traffic modelling.

## How MATSim Works

MATSim is an agent-based simulation framework. Each agent has a day plan (home → work → shop → home) and competes for road capacity. Scores are calculated per plan; over iterations, agents learn better routes.

Key concepts:
- **Network** — nodes and directed links, each with capacity and free-flow speed
- **Plans** — each agent's activity chain with locations and times
- **Events** — emitted per-second as agents move; we stream these to the frontend
- **Scoring** — each plan gets a utility score; agents copy high-scoring plans over iterations

## Agent Plan Generation

Plans are generated by `trafficjam-be` based on scenario config:
- Population density → number of agents
- Job-to-bed ratio → split between residential and employment zones
- Shopping probability, healthcare chance, errand duration, etc.

See `investigations/agent-plans/AGENT-PLANS.md` for full details.

## Scoring

MATSim scores plans using Charypar-Nagel utility function:
- Time spent at activities (positive)
- Travel time (negative)
- Late arrival / early departure penalties

See `investigations/MatSim-Scoring/investigation.md`.

## Events Stream

Events flow: `simengine` → NATS JetStream → `trafficjam-be` → SSE → `trafficjam-fe`

Event types used:
- `linkEnterEvent` — agent enters a road link
- `linkLeaveEvent` — agent leaves a road link
- `actStartEvent` / `actEndEvent` — activity start/end
