AGENTS.md — BIMS 5 Urban Simulation Platform

    Orchestrating the transition from historical data visualization to predictive urban simulation.

Agent Roster
🕒 CHRONOS AGENT (The Historian)

Mission: Reconstruct a city's evolution using historical datasets.
Tasks:

    Map the timeline of major completions (transport hubs, university campuses, residential developments).

    Index historical traffic datasets and population shifts.

    Output: /data/history/city-snapshot.json (A year-by-year snapshot of the city's state).

🎨 CARTOGRAPHER AGENT (The Visualizer)

Mission: Build the "Innovative 2D Map" that evolves seamlessly over time.
Tasks:

    Handle the Temporal Slider logic: Smoothly interpolate between building footprints and road layouts.

    Design the "Ghosting" effect: Show old structures fading out as new ones rise.

    Integrate heatmaps for population density and traffic flow directly onto the 2D plane.

    Output: /client/components/map/TimeMap.tsx

🧠 NEURAL PLANNER (The Forecaster)

Mission: Predict how user-added buildings/roads affect the city over the forecast horizon.
Tasks:

    Population Engine: Factor in the "Job-to-Bed" ratio. Adding an office building increases daytime population; adding apartments increases local demand for services.

    Traffic Stress-Test: Simulate new road impacts on the existing network. Use "Induced Demand" logic—will the new road actually fix traffic, or just move the bottleneck?

    Economic Loop: Calculate the revenue generated by user additions vs. the infrastructure cost.

🛠️ SANDBOX AGENT (The Architect)

Mission: Handle the "Introduction" of new assets by the user at any point in the timeline.
Tasks:

    Placement Logic: Ensure user-added assets respect (or intentionally break) current zoning.

    Scenario Branching: If a user adds a road in year N, calculate two futures: Timeline A (No Road) vs. Timeline B (With Road).

    Output: /sim/scenarios/[user-id]/branch-v1.json

Standard Simulation Workflow
Phase 1: The Review (Historical)

    User slides back to the start year.

    Chronos Agent fetches the historical map state.

    Cartographer Agent renders the 2D vector map.

    User slides forward; the map "grows" as data points are triggered.

Phase 2: The Intervention (Forecast)

    User stops at the present and clicks "Add Building."

    Sandbox Agent creates a new simulation branch.

    Neural Planner calculates the ripple effects:

        Impact 1: Congestion on key arterials increases by X%.

        Impact 2: Potential annual tax revenue increases by £Y.

    Cartographer Agent updates the forecast on the map visually (e.g., roads turning red for traffic).

Quality Standards

    Accuracy: Use specific local landmarks and official datasets as anchors.

    Performance: Simulations must run in <2 seconds to keep the slider feeling "live."

    Innovative UI: Use a "Split-Screen" or "Overlay" mode where users can compare their simulated future against official planning documents.

Orchestration Rules

    No Infinite Growth: The Neural Planner must cap population based on the actual physical limits of the city boundary.

    Road Logic: If a user adds a road that disconnects a community, the "Social Equity" score (a hidden metric) must drop, affecting long-term population retention.

    The "Butterfly Effect": A change made in year N must automatically update all subsequent years in that branch.
